发张电影票，Agent自动生成专属纪念票根

2026-10-18

之前（快一年了）做过一个网页版的电影票根设计项目 EverStub，需要自己上传海报、手动填写电影的中英文名、场次、票价和影院信息。以我现在的懒惰程度，这种交互几乎是无法接受、无法原谅的。

最近给 Agent 提供了之前版本的源码，重构成了一个 Skill movie-ticket-stub1。

现在不需要自己填信息了。不管是一张订单截图，还是随手拍一张纸质票发过去，Agent 都能自动跑完识票、找海报、风格转绘到排版归档的全流程。

实付 32 块，给 Agent 补充一下信息。

直接复用了之前版本反复调试出的排版方式，能保证生成的票根在字体、行距与比例上和之前的网页版完全一致。

风格迁移之必要

你早就可以在网上搜到很多电影票根项目，理论上说，一年之后的今天可以搜到更多。

这些项目大多分两派：有些直接拿官方原版海报，有些则是自己手绘。对于前者，各家电影宣发审美参差不齐，攒下来的票根风格很难统一；对于后者，你可能会画画，但我不会。

我的选择是转绘。

比如说，你翻了一圈物料，却只对日版先导海报的构图感到满意。但我又不是在日本看的电影，直接在票面上顶着一行片假名还是显得过于野蛮。通过固定风格的转绘，刚好可以把画面里的文字去掉。

想让生图模型稳定输出这种“只留构图、不留文字”的扁平插画，提示词约束的核心是这四条：

  1. 构图继承：严格沿用参考海报的主体剪影轮廓、透视焦点与空间布局。
  2. 色彩与风格：采用高对比度的纯色几何平面，配色直接提炼自原片海报的视觉识别系统。
  3. 清除文字：彻底清除画面中的所有片名、字幕、演职员名单与商业 Logo，将原文字区域转化为纯粹的平涂色块或负空间。
  4. 画幅规格：输出单张无白边全出血（Full Bleed）的 1:1 正方形插画，严禁添加任何边框或画框。

工作流之爆发夜

工作流这种东西，一开始总是很简单的：

  1. 多模态模型识别票面信息，转成 JSON 结构化数据；
  2. 联网搜索电影的官方英文名与高清海报；
  3. 用写好的提示词转绘成无文字的 1:1 固定风格插画；
  4. 用程序把插画和票面信息拼合渲染出来。

但用户可能会遇到各种真实场景下的边界情况：热敏纸反光字迹看不清、出现同名电影不确定是哪一部、生图偶尔溢出一圈白边……

把这些问题逐个反馈给 Agent、反复打完补丁后，就有了这个看似复杂的工作流：

其实和我前面写的这 4 步没什么区别，无非是多加了一些让 Agent 在信息拿不准时主动停下来求证的步骤，把排版交给本地脚本保证确定性。总而言之，是让 Agent 养成一些好习惯。

重组 Skill：顺手做个光栅卡

把工具封装成 Skill 的另一个好处，是你随时可以把它嵌进其他工作流。

比如我之前见过一个生成 3D 光栅卡的技能 holo-card-studio2。完全不需要改代码，直接让 Agent 结合这两个技能做一张电影票根，执行过程中的 Agent 会主动让你选择光栅样式。
